# 3D Physics Bodies (Xogot 3D Tutorial)

This project contains the example scenes and assets used in the **Xogot 3D Modular Series – Introduction to 3D Physics Bodies** tutorial by **Erin Uptegrove**.

It demonstrates how to use the core **3D physics body types** in **Xogot** — the iPad and iPhone port of the Godot Engine — and shows how they interact with forces, collisions, and gameplay systems in a 3D scene.

The project includes sample scenes that illustrate when to use **StaticBody3D**, **AnimatableBody3D**, **RigidBody3D**, **CharacterBody3D**, and **VehicleBody3D**, along with practical examples like platforms, moving objects, and physics-driven interactions.

---

## Features

* Use **StaticBody3D** for stationary environment objects like walls and platforms
* Use **AnimatableBody3D** for moving objects such as platforms and doors
* Use **RigidBody3D** for physics-driven objects affected by gravity and forces
* Use **CharacterBody3D** for player-controlled movement
* Explore **VehicleBody3D** for basic vehicle simulation
* Understand how physics bodies interact with collisions and other objects
* Compare how different body types behave in similar scenarios
* Preview gameplay interactions directly in example scenes

---

## Notes

This project focuses on **choosing and using the correct physics body type**, rather than advanced physics configuration or scripting.

Key ideas demonstrated include:

* Static bodies do not respond to forces but can be collided with
* Animatable bodies can move manually and affect other objects
* Rigid bodies are fully controlled by physics simulation
* Character bodies are designed for player-controlled movement
* Different body types are suited to different gameplay roles

## How to Use

1. Download or clone this repository:

   ```bash
   git clone https://github.com/xogot-projects/Xogot-PhysicsBody3D.git
   ```

2. Open the project in **Xogot** on iPad or iPhone.

3. Explore the included scenes:

   * Static platform examples
   * Moving platform (AnimatableBody3D)
   * Rigid body interaction examples
   * Player-controlled CharacterBody3D scenes
   * Vehicle-based examples

4. Run the scenes to observe how different physics bodies behave and interact.

5. Modify or swap physics body types to compare behavior and better understand their use cases.
